# Harness docs

The harness helps an AI coding agent finish one piece of work, step by step.
You talk to the agent in your chat. A small program, the engine, keeps track of the work.
The engine checks each step before the agent can move on.

Read the pages in this order:

1. [What it is](1-what-it-is.md): the problems it solves and the main idea.
2. [First run](2-first-run.md): install it and follow one ticket from start to end.
3. [Phases](3-phases.md): the five steps, who does each one, and what each check looks at.
4. [Daily use](4-daily-use.md): extra requests, checkpoints, code review, red CI.
5. [Rules](5-rules.md): how agents keep the same code style.
6. [Engine](6-engine.md): the tools, the files and the checks inside.
7. [Safety](7-safety.md): what stops an agent from doing damage, and the limits.
8. [Extending](8-extending.md): add a phase, a check, a language or a tool.
